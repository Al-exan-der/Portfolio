# Documentación cronológica — Portfolio

**Período:** 9 al 18 de noviembre de 2026

Durante este período desarrollé y publiqué mi portfolio personal con Astro. Comencé desde la estructura inicial del framework, construí la presentación y las tarjetas de proyectos, definí criterios visuales y de espaciado, y preparé los archivos para su presentación. Las actividades se ordenan según los commits de la rama `main` y se agrupan cuando corresponden a una misma etapa.

| Fecha | Actividades realizadas |
|---|---|
| **9 de noviembre** | **Inicio del proyecto.** Inicié el proyecto a partir de la plantilla mínima de Astro. Este commit dejó creada la estructura base, la configuración inicial y las dependencias sobre las que desarrollé el portfolio. |
| **10 de noviembre** | **Estructura inicial y repositorio.** Reemplacé la página de ejemplo por una primera estructura en español, con navegación a Inicio, Proyectos y CV, las secciones principales y el pie de página. Creé la hoja de estilos global con la paleta inicial y el contenedor general. También registré el repositorio y trasladé la documentación a la carpeta `docs/`. |
| **17 de noviembre** | **Tipografía y sistema de espaciado.** Configuré las fuentes Oxanium e Inter mediante Fontsource en Astro y ajusté su carga desde la página. Definí una escala de espaciado con valores de 4, 8, 16, 24, 32, 48 y 80 px, expuestos como variables CSS para mantener una separación consistente. |
| **17 de noviembre** | **Configuración y publicación.** Preparé Astro para publicar el sitio en GitHub Pages, configurando el dominio y la ruta base `/Portfolio`. Adapté las rutas del favicon y del CV para que funcionaran bajo esa dirección. Añadí un workflow de GitHub Actions para compilar y desplegar el proyecto y confirmé que quedara publicado. |
| **18 de noviembre** | **Creación de las tarjetas.** Organicé los datos de Proyecto Islas, Reactstore y Tetris en una estructura de proyectos y generé sus tarjetas mediante un recorrido del array. Construí una grilla adaptable y definí el aspecto inicial de las cards, con fondo propio, esquina recortada, títulos, descripciones y botón de acceso. |
| **18 de noviembre** | **Portada y composición visual.** Añadí el avatar y el contenido de presentación personal, junto con los enlaces a GitHub, LinkedIn y correo. Ajusté la distribución flexible de la portada, el tamaño de las tarjetas, las separaciones entre elementos y el espaciado de las distintas secciones. |
| **18 de noviembre** | **Iconos, navegación e interacciones.** Incorporé las capturas de los proyectos como enlaces a sus repositorios y añadí efectos de ampliación y superposición al pasar el cursor. Implementé iconos de redes y tecnologías mediante máscaras CSS. También ajusté la navegación fija, el desplazamiento suave, los estados de foco y la preferencia de movimiento reducido. |
| **18 de noviembre** | **Contenido y correcciones.** Amplié las descripciones de los proyectos para explicar sus funciones y especificar mi contribución en cada uno. Corregí el archivo del CV, tipé el mapa de iconos con `Record<string, string>` y desactivé la barra de desarrollo de Astro. |
| **18 de noviembre** | **Optimización de imágenes y fuentes.** Convertí las capturas de los proyectos y el avatar a WebP y actualicé sus referencias. Probé una relación de aspecto 16:9 para las imágenes de las tarjetas, pero en el ajuste posterior volví a 1:1. También corregí las referencias CSS a las variables de las fuentes generadas por Astro. |
| **18 de noviembre** | **Presentación y cierre.** Añadí las presentaciones de CSS y de HTML/Astro, actualicé el README con la descripción y las instrucciones del proyecto, incorporé el prototipo de Penpot en formato PDF y amplié el avatar para darle mayor presencia en la portada. |
| **18 de noviembre** | **Correcciones finales y herramientas.** Actualicé la referencia de MySQL a MariaDB en el mapa de iconos, la lista de tecnologías y la descripción de Reactstore. También corregí el README para utilizar PNPM en la instalación y ejecución del proyecto, y eliminé `package-lock.json` para conservar `pnpm-lock.yaml` como único archivo de bloqueo. |
| **18 de noviembre** | **Organización de archivos.** Separé los recursos necesarios para publicar la web de los materiales de entrega. Agrupé el CV y las imágenes en subcarpetas dentro de `public/`, trasladé las presentaciones y el prototipo de Penpot a `docs/`, actualicé las rutas del sitio y el README, y unifiqué la identidad visual de ambas documentaciones. |
